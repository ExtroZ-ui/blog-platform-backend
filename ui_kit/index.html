UI Kit для итогового проекта

Базовая дизайн-система для платформы блогов

Набор адаптивных компонентов интерфейса: кнопки, поля ввода, выпадающие списки, чекбоксы, радиокнопки, карточки, навигация, контейнеры и grid-сетки.

Смотреть компоненты Примеры карточек

1. Button

Компонент кнопки поддерживает варианты primary, secondary и disabled, а также размеры small, medium и large. 

<button class="button button--primary button--medium">Primary</button>

2. Input

Поле ввода поддерживает обычное состояние, фокус, ошибку и иконку.

⌕

Логин должен содержать минимум 3 символа.

<div class="input input--error">
    <label class="input__label">Логин</label>
    <input class="input__control" type="text">
    <p class="input__error">Ошибка ввода</p>
</div>

3. Dropdown

Выпадающий список можно использовать для выбора категории статьи. 

<select class="dropdown__control">
    <option>Технологии</option>
</select>

4. Checkbox и Radio

Компоненты подходят для фильтров, настроек и выбора статуса публикации.

5. Card

Карточка содержит заголовок, изображение и текст. Есть модификаторы с изображением, без изображения и размеры small, medium, large.

Технологии

Короткая карточка

Небольшое описание статьи для списка публикаций.

Образование

Средняя карточка статьи

Такой вариант можно использовать на главной странице блога или в списке популярных материалов.

Без изображения

Большая карточка без изображения

Карточка без изображения подходит для текстовых материалов, заметок, черновиков или элементов личного кабинета автора. 

<article class="card card--medium card--with-image">
    <img class="card__image" src="image.jpg" alt="...">
    <div class="card__body">
        <h3 class="card__title">Заголовок</h3>
        <p class="card__text">Описание</p>
    </div>
</article>

6. Flexbox и Grid

Для выравнивания используется центральный контейнер, flex-обёртки и адаптивная grid-сетка карточек.
